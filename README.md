# Brooke's Reading Room

An interactive 3D study and a separate literary bookshelf for Brooke.

## Local preview

Run a static server from the project directory, then open:

- Main 3D room: `http://127.0.0.1:4173/`
- Reading room: `http://127.0.0.1:4173/bookshelf/`

The bookshelf catalog lives in `bookshelf/books.tsv`. To add a book, place its cover in `assets/books/covers/`, append one row to the table, and refresh the reading-room page. More details are available in `bookshelf/BOOKS.md`.
